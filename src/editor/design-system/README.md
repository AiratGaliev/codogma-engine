# Codogma Editor — дизайн-токены

Единый источник цветовых ролей для макета Codogma Editor и Godot SVG icon pack — `tokens.json`.

## Темы и роли

Все цветовые роли определены для двух режимов: `dark` и `light`.

- `surface-*` — поверхности рабочего пространства, панелей, тулбаров, контролов, hover и selected states.
- `border-*` — разделители, границы контролов и акцентные границы.
- `text-*` — основной, вторичный, третичный и disabled-текст.
- `accent-*` — активный инструмент, выделение и выбранные элементы.
- `semantic-*` — статусы success, warning, danger и info.
- `icon-*` — нейтральные и категорийные иконки Godot.
- `particle-palette-*` — пользовательские цвета эмиттера частиц. Это значения данных, а не цвета интерфейсной темы.

Токены не требуют одинакового HEX в обеих темах. Важны семантика роли, контраст и устойчивость визуальной иерархии.

## Требования к контрасту

Автоматические проверки используют следующие целевые значения относительно поверхностей workspace, panel и inset:

- текстовые роли и текстовые семантические статусы: не менее 4.5:1;
- основные графические роли иконок: не менее 3:1;
- `text-disabled`, прозрачные декоративные слои и пользовательские particle swatches — намеренные исключения.

Цвета частиц нельзя автоматически перекрашивать при смене темы: это содержимое проекта, а не оформление редактора.

## Использование в Pencil

Визуальные свойства ссылаются на токены, например:

- `fill: "$surface-panel"`
- `fill: "$text-primary"`
- `stroke: "$border-subtle"`
- `fill: "$semantic-warning"`

Для корректного переключения темы каждый тематический артборд должен явно задавать `theme.mode`. Текстовые значения, которые показывают HEX-код как данные (например, поле Tint), остаются литералами и не заменяются ссылками на токены.

## Godot SVG и Pencil

Исходные файлы в `src/editor/icons/{dark,light}/godot` — единственный источник геометрии. Pencil не загружает SVG как обычную image-заливку, поэтому importer преобразует SVG shapes в редактируемые `path` nodes. Каждый icon frame хранит исходный SVG path, upstream revision и MIT license в metadata.

Light SVG генерируются из тёмных исходников по `lightIconColorMap` из `tokens.json`. Исключение — многоцветный `particle-material.svg`: палитра swatches остаётся исходной.

## Обновление после изменения токенов или SVG

Из корня репозитория:

```powershell
node scripts/generate-godot-light-icons.mjs
node scripts/import-godot-svg-icons-to-pen.mjs
node scripts/apply-design-tokens-to-pen.mjs
```

Первый скрипт обновляет тематические SVG. Второй перестраивает нативную векторную геометрию и применяет токены к path fills/strokes. Третий обновляет ссылки UI-цветов и таблицу переменных Pencil. Скрипты работают поверх существующего `codogma-editor.pen`.

## Проверки

```powershell
node --test tests/godot-icons.test.mjs tests/codogma-editor-pen-assets.test.mjs
npm run test:unit
npm run build
```

Тесты проверяют полноту SVG-набора и token maps, контраст обеих тем, количество и происхождение нативных path nodes, явную тему иконок, сохранность текстовых HEX-значений и повторяемость импорта.
