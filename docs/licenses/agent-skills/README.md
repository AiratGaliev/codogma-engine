| Source repository | Installed skills | Licence evidence |
|---|---|---|
| [anthropics/skills](https://github.com/anthropics/skills) | frontend-design, mcp-builder | Each skill copy includes its own LICENSE.txt (Apache-2.0). |

| [phaserjs/phaser](https://github.com/phaserjs/phaser) | 28 Phaser 4 skills | MIT-Phaser.txt; official Phaser package metadata identifies Phaser 4.2.1 as MIT. |

| [richardcarls/solid-js-best-practices](https://github.com/richardcarls/solid-js-best-practices) | solid-js-best-practices | MIT-RichardCarls-SolidJS.txt. Community-maintained, Solid 1.x-based guidance; version checks are mandatory. |
| [ayubjon/yandex-games-skill](https://github.com/ayubjon/yandex-games-skill) | yandex-games-dev | MIT-Ayubjon-Yandex-Games.txt. Includes a separately MIT-licensed, pinned upstream checker; see the skill's provenance notes. |

| [antfu/skills](https://github.com/antfu/skills) | vite | The upstream README states that its skills/scripts are MIT-licensed; the skill metadata says it is generated from Vite documentation. MIT-Vite.txt preserves the underlying Vite project documentation licence. |

The licence files are retained for attribution and redistribution compliance. They do not imply that every skill is equally authoritative or automatically applicable to Codogma Engine. See [docs/agent-skills.md](../../agent-skills.md) for selection rules and stack limitations.
