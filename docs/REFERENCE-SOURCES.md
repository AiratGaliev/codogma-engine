# Каталог технических источников Codogma Engine

**Дата проверки:** 26.10.2026  
**Назначение:** быстрые ссылки на документацию и исходники, используемые при принятии архитектурных решений по ТЗ и roadmap.

Этот документ — индекс reference-материалов, а не список зависимостей к установке. Ссылки ведут на официальную документацию/репозитории там, где это возможно. Перед реализацией конкретной задачи перепроверь версию API, дату документации, совместимость с текущим Phaser 4.2.1, лицензию и зависимые лицензии. Запись в каталоге не означает, что библиотека выбрана или функциональность Codogma уже реализована.

**Критические различия версий:** руководство Cocos Creator 4.0 и исходный репозиторий cocos/cocos4 — разные reference-источники, их нельзя считать взаимозаменяемыми. Руководство Unity 6000.6 используется для 2D workflow, а не как требование скопировать Unity packages/URP. Для внешнего кода перед заимствованием фиксировать конкретный commit/tag и обязательные notices.
