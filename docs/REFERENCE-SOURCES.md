# Каталог технических источников Codogma Engine

**Дата проверки:** 30.10.2026  
**Назначение:** быстрые ссылки на документацию и исходники, используемые при принятии архитектурных решений по ТЗ и roadmap.

Этот документ — индекс reference-материалов, а не список зависимостей к установке. Текущее состояние проверенного baseline: `source/editor/package.json` содержит TypeScript 5.3.3, а `npm run build` вызывает `tsc -b`. Зависимость TSLint удалена в PR #10, хотя `source/editor/tslint.json` и `source/editor/lint.sh` ещё лежат в дереве и не являются активным CI gate. ESLint, Prettier, Knip и dependency-cruiser указаны как целевой toolchain, но ещё не установлены в root/editor manifests. Ссылки ведут на официальную документацию/репозитории там, где это возможно. Перед реализацией конкретной задачи перепроверь версию API, дату документации, совместимость с текущим Phaser 4.2.1, лицензию и зависимые лицензии. Запись в каталоге не означает, что библиотека выбрана или функциональность Codogma уже реализована.

**Критические различия версий:** руководство Creator 4.0 и отдельный исходный репозиторий `cocos/cocos4` — разные reference-источники, не взаимозаменяемые API. Страница Creator 4.0 обозначает себя как LTS, но одновременно называет Creator 3.x последней версией; поэтому фиксировать конкретную версию и проверять release availability/API перед использованием как эталона. Ниже добавлен отдельный reference на Creator 3.8 LTS. На 30.10.2026 Unity 6000.6 помечена как Current, 6000.3 и 6000.0 — LTS, а 6000.7 — Beta; поэтому стабильные архитектурные решения сверять с 6000.6/LTS, Beta использовать отдельно как standards-watch. Для внешнего кода фиксировать commit/tag, лицензию и upstream notices.

Поведение сторонних библиотек уточняется по официальной документации; собственные контракты Codogma определяются ТЗ и ADR.
